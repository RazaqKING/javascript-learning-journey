# Day 1: Personal Intro Card

A small Node.js program that prints a formatted profile card in the terminal, then updates a progress counter.

## Run it
```bash
node intro-card.js
```

## Output
```
==============================
     PERSONAL INTRO CARD
==============================
Name:      AbdulRazaq
Country:   Nigeria
Role:      Software Engineer
Goal:      To become a full-stack developer
Favorite:  Learning New Things
Days done: 0
==============================
Update: I have completed 1 day(s) of JavaScript!
```

## What I practised
- `console.log` and statements
- Declaring variables with `const` (never reassigned) and `let` (reassigned)
- Reassigning a variable: `daysCompleted = daysCompleted + 1`
- Joining strings with `+` and aligning output
- Organising code into sections: data → output → updates
